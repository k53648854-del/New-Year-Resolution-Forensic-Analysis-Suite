# New Year Resolution Forensic Analysis Suite

## Overview

The New Year Resolution Forensic Analysis Suite is a comprehensive blockchain-based system designed to conduct post-mortem examinations of ambitious January goals that mysteriously died around February 3rd. This suite provides forensic analysis capabilities to understand the lifecycle of New Year resolutions and the psychological impact of unfulfilled commitments.

## System Description

This suite consists of two main smart contracts that work in tandem to provide complete forensic analysis of failed New Year resolutions:

### 1. Resolution Autopsy Timeline Reconstructor
This contract specializes in pinpointing the exact moment when "this year will be different" transformed into "maybe next year will be different". It tracks:
- Resolution creation timestamps
- Milestone tracking
- Failure event detection
- Timeline reconstruction capabilities

### 2. Gym Membership Guilt Accumulation Calculator
This contract computes the mounting psychological weight of unused January fitness commitments by December. It manages:
- Membership tracking
- Usage statistics
- Guilt accumulation algorithms
- Psychological impact assessments

## Features

- **Forensic Timeline Analysis**: Track and analyze the complete lifecycle of resolutions
- **Psychological Impact Calculation**: Quantify the guilt and regret associated with failed commitments
- **Data-Driven Insights**: Provide statistical analysis of resolution failure patterns
- **Blockchain Transparency**: Immutable record of commitments and failures
- **Community Analytics**: Aggregate data for broader behavioral insights

## Technology Stack

- **Blockchain**: Stacks blockchain using Clarity smart contracts
- **Smart Contract Language**: Clarity (.clar)
- **Development Framework**: Clarinet
- **Testing**: Vitest framework
- **Version Control**: Git with GitHub integration

## Contract Architecture

### Resolution Autopsy Timeline Reconstructor
- Manages resolution creation and tracking
- Implements timeline reconstruction algorithms
- Provides failure point identification
- Tracks behavioral patterns over time

### Gym Membership Guilt Accumulation Calculator
- Tracks gym membership utilization
- Calculates guilt accumulation over time
- Provides psychological impact metrics
- Generates usage statistics and reports

## Installation & Setup

1. Ensure you have Clarinet installed
2. Clone the repository
3. Navigate to the project directory
4. Run `clarinet check` to validate contracts
5. Use `clarinet test` to run the test suite

- Generating forensic reports
- Analyzing behavioral patterns
